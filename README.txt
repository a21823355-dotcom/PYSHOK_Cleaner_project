=====================================================

Разработчик: PYSHOK LAB

ИСПРАВЛЕНО В 2.1:
  - Больше НЕ мелькают окна командной строки при работе программы
    (очистка реестра, оптимизация дисков, сброс DNS и т.д. теперь
    выполняются полностью в фоне, без видимых окон консоли)
  - Исправлен поиск битых ярлыков (вкладка "Инструменты") — раньше
    он мог тихо не срабатывать в собранном exe из-за особенностей
    библиотеки pywin32; теперь используется свой лёгкий разбор
    .lnk-файлов без внешних зависимостей — работает надёжно
  - У программы теперь есть собственная иконка (щит с галочкой)

НОВОЕ:
  - Вкладка "Программы": список установленных программ, потенциально
    нежелательные (тулбары, рекламный софт и т.п.) подсвечены
    красным. Удаление запускает штатный деинсталлятор программы —
    ровно то же самое, что делает "Установка и удаление программ"
    в Windows. Ничего не удаляется мимо official-деинсталлятора.
  - На вкладке "Очистка" — кнопка "Оценить объём мусора": перед
    очисткой можно посмотреть, сколько места занимает каждая
    категория (temp, кэш браузеров, Windows Update и т.д.)
  - В шапке программы — информация о системе (ОС, загрузка ОЗУ)

ВСЁ ОСТАЛЬНОЕ КАК В 2.0:
  - Очистка мусора (temp, кэш, корзина, безопасные записи реестра)
  - Оптимизация дисков (TRIM для SSD / дефрагментация для HDD)
  - Менеджер автозагрузки с подсветкой подозрительных записей
  - Запуск проверки встроенным Windows Defender (см. пояснение ниже)
  - Поиск больших файлов
  - Выбор языка интерфейса RU/EN (переключатель в шапке)

О "БЕЗОПАСНОСТИ" ЧЕСТНО:
  Программа НЕ является отдельным антивирусом. Написать свой
  антивирусный движок с нуля бессмысленно — без постоянно
  обновляемой базы сигнатур такой "антивирус" не защищает, а лишь
  создаёт ложное чувство безопасности. Вместо этого вкладка
  "Безопасность" запускает проверку уже встроенным в Windows
  Defender — он бесплатный, всегда на месте и обновляется Microsoft.

БЕЗОПАСНОСТЬ ПОДХОДА:
  - Реестр и автозагрузка меняются только после успешного бэкапа
  - Списки на удаление (большие файлы, битые ярлыки, программы,
    автозагрузка) всегда показываются пользователю — удаление
    только по явному выбору и подтверждению
  - Удаление программ — только через их официальный деинсталлятор
  - Программа не трогает личные файлы

КАК ПОЛУЧИТЬ .EXE:

СПОСОБ 1 (в облаке, ничего не устанавливать):
  1. Загрузите обновлённые cleaner.py, version_info.txt, icon.ico
     и .github/workflows/build.yml в свой репозиторий на GitHub
     (замените старые файлы)
  2. Вкладка Actions — сборка запустится автоматически
  3. Через 1-2 минуты скачайте готовый exe из Artifacts

СПОСОБ 2 (на своём Windows-компьютере):
  1. Установите Python с python.org (галочка "Add to PATH")
  2. Файлы cleaner.py, version_info.txt, icon.ico, build_exe.bat —
     в одну папку
  3. Дважды кликните build_exe.bat
  4. Готовый exe — в папке dist\PYSHOK_Cleaner.exe, уже со своей
     иконкой
