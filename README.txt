ЧТО УМЕЕТ ВЕРСИЯ 2.0 (вкладки в программе):

1) ОЧИСТКА
   - Всё, что было раньше (temp, кэш браузеров, корзина, WER,
     миниатюры, кэш Windows Update, безопасные MRU-списки реестра)
   - + кэш шрифтов, сброс DNS, пустые папки в AppData\Temp
   - + удаление "осиротевших" записей в Установка и удаление
     программ (когда программа уже удалена вручную, а запись
     осталась) — с автоматическим бэкапом реестра

2) ДИСКИ
   - Показывает все несъёмные диски, определяет SSD или HDD
   - Для SSD выполняет TRIM (Optimize-Volume -ReTrim)
   - Для HDD выполняет дефрагментацию (Optimize-Volume -Defrag)
   - Это штатные функции Windows, ничего стороннего не ставится

3) АВТОЗАГРУЗКА
   - Список всех программ в автозагрузке (реестр + папки Startup)
   - Подозрительные записи (например, запускаются из Temp или
     ссылаются на несуществующий файл) подсвечиваются красным
   - Удаление — с автоматическим бэкапом в
     Документы\PYSHOK_Cleaner_Backups

4) БЕЗОПАСНОСТЬ
   ВАЖНО: это НЕ отдельный антивирус. Написать свой антивирусный
   движок с нуля бессмысленно — без постоянно обновляемой базы
   сигнатур и глубокой интеграции в систему такой "антивирус"
   не защищает, а лишь создаёт ложное чувство безопасности.
   Вместо этого программа:
   - Показывает статус встроенного Windows Defender
   - Запускает быструю или полную проверку самим Defender'ом
   - Отдельно проверяет автозагрузку на подозрительные записи
     (эвристика: запуск из временных папок, битые пути)

5) ИНСТРУМЕНТЫ
   - Поиск битых ярлыков на рабочем столе и в меню Пуск
     (ярлык есть, а программа, на которую он ссылается, удалена)
   - Поиск больших файлов в выбранной папке с ручным удалением

ВЫБОР ЯЗЫКА:
   В правом верхнем углу — переключатель RU / EN, меняет
   интерфейс сразу же.

БЕЗОПАСНОСТЬ ПОДХОДА:
   - Реестр и автозагрузка меняются только после успешного
     бэкапа — если бэкап не удался, изменение отменяется
   - Ничего не удаляется "втихую": списки файлов на удаление
     (большие файлы, битые ярлыки, автозагрузка) показываются
     пользователю, удаление — только по явному выбору и кнопке
   - Программа не трогает установленные программы и личные файлы

КАК ПОЛУЧИТЬ .EXE:

СПОСОБ 1 (в облаке, ничего не устанавливать):
  1. Загрузите обновлённые cleaner.py, version_info.txt и
     .github/workflows/build.yml в свой репозиторий на GitHub
     (замените старые файлы)
  2. Вкладка Actions — сборка запустится автоматически
  3. Через 1-2 минуты скачайте готовый exe из Artifacts

СПОСОБ 2 (на своём Windows-компьютере):
  1. Установите Python с python.org (галочка "Add to PATH")
  2. Файлы cleaner.py, version_info.txt, build_exe.bat — в одну папку
  3. Дважды кликните build_exe.bat (теперь заодно ставит pywin32)
  4. Готовый exe — в папке dist\PYSHOK_Cleaner.exe
