PYSHOK Cleaner 1.0.0 — что это и как получить .exe
=====================================================

ЧЕСТНО О ГЛАВНОМ:
Я работаю в Linux-песочнице и не могу скомпилировать нативный
Windows .exe прямо здесь (для этого нужен сам Windows). Поэтому я
подготовил ПОЛНОСТЬЮ ГОТОВЫЙ исходный код и скрипт, который на вашем
компьютере за 30 секунд соберёт настоящий .exe одним двойным кликом.

ЧТО В ПАПКЕ:
  cleaner.py        — сам код программы (GUI на tkinter)
  version_info.txt   — данные для свойств exe (разработчик: PYSHOK LAB)
  build_exe.bat       — сборка exe одним кликом
  README.txt          — этот файл

СПОСОБ 1 (ничего не устанавливать на свой компьютер, самый простой):
  Сборка exe происходит автоматически в облаке через GitHub Actions.
  1. Зайдите на https://github.com и создайте бесплатный аккаунт
     (если его ещё нет)
  2. Создайте новый репозиторий (кнопка "New repository"), можно
     приватный
  3. Перетащите туда ВСЕ файлы из этой папки, включая скрытую
     папку .github (в ней лежит .github/workflows/build.yml —
     именно она запускает автосборку)
  4. Откройте вкладку "Actions" в репозитории — сборка запустится
     сама в течение 5-10 секунд после загрузки файлов
  5. Через 1-2 минуты сборка завершится (зелёная галочка). Зайдите
     в неё и внизу страницы скачайте архив "PYSHOK_Cleaner" —
     внутри готовый PYSHOK_Cleaner.exe
  Больше ничего делать не нужно — Python, PyInstaller и сама
  компиляция происходят на серверах GitHub, не на вашем компьютере.

СПОСОБ 2 (если есть Windows и не хочется заводить GitHub):
  1. Скачайте и установите Python с https://python.org
     (при установке ОБЯЗАТЕЛЬНО отметить "Add python.exe to PATH")
  2. Положите файлы cleaner.py, version_info.txt, build_exe.bat в
     одну папку
  3. Дважды кликните build_exe.bat
  4. Дождитесь надписи "Готово!" — файл появится в папке dist\PYSHOK_Cleaner.exe

ЧТО ДЕЛАЕТ ПРОГРАММА:
  - Временные файлы пользователя и системы (%TEMP%, Windows\Temp)
  - Prefetch (кэш запуска программ)
  - Корзина
  - Кэш загрузок Windows Update
  - Отчёты об ошибках Windows (WER)
  - Кэш эскизов (миниатюр)
  - Кэш браузеров: Chrome, Edge, Yandex, Opera GX, Firefox
  - (опционально) безопасная очистка MRU-списков реестра
    ("последние открытые файлы/пути") — с автоматическим бэкапом
    реестра в Документы\PYSHOK_Cleaner_Backups перед изменением

ЧЕГО ПРОГРАММА НЕ ДЕЛАЕТ (специально):
  - НЕ удаляет установленные программы
  - НЕ трогает личные файлы (документы, фото, музыку)
  - НЕ чистит "агрессивные" ветки реестра (UserAssist, автозапуск
    и т.п.) — такие правки чаще ломают систему, чем помогают,
    поэтому сознательно исключены ради надёжности
  - НЕ удаляет пароли/историю/закладки браузеров — только файлы кэша

БЕЗОПАСНОСТЬ:
  - При запуске без прав администратора программа честно покажет
    об этом и предложит кнопку "Перезапустить с правами администратора"
  - Реестр меняется только после успешного создания .reg-бэкапа;
    если бэкап не удался — очистка реестра отменяется автоматически
  - Все ошибки доступа (занятые файлы и т.п.) просто пропускаются,
    программа не падает и не портит систему
